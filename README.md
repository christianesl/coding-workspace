# coding-workspace

A Java practice workspace covering core language and algorithm fundamentals — a scratch space for exercises and small labs.

## What's inside
- `src/lab/` — general Java exercises (loops, booleans, lambdas, Swing UI demo, list reversal, Tic-Tac-Toe, "Hello World")
- `src/bitsManipulation/` — bit manipulation and subset-sum practice
- `src/regex/` — regular expression exercises
- `src/MortgageCadence/` — a multi-row relationship exercise

## Stack
Java

## Notes
Each file under `src/` is a self-contained exercise; there's no single entry point — compile and run individual classes as needed.
